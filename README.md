# 🏰 **Forte**

**Forte** is a secure and portable private notes manager, designed for storing sensitive short data like passwords, ideas, and links.

Notes are organized in encrypted containers, allowing users to export, import, and synchronize them across devices via services like Google Drive — always protected by a personal password.

Just like a stronghold built to safeguard what matters, Forte exists to protect your most valuable information.
